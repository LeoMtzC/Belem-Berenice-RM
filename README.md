# Portafolio web — Belem Berenice Remigio Moreno

Versión inicial de un portafolio profesional de Mercadotecnia, Contenido y Diseño.

## Archivos
- `index.html` — sitio completo.
- `styles.css` — diseño responsive, animaciones y sistema visual.
- `script.js` — scroll progress, reveal animations y microinteracciones.
- `CV_Belem_Berenice_Remigio_Moreno_2026.docx` — CV proporcionado.
- `PORTAFOLIO.pdf` — portafolio proporcionado.
- `assets/` — recursos visuales derivados del portafolio proporcionado.

## Cómo verlo
Abre `index.html` en un navegador. Para publicarlo, puedes subir toda la carpeta a cualquier hosting estático.

## Nota
El contenido está basado en el CV y portafolio proporcionados. Los textos de marketing de la interfaz fueron redactados para presentar ese contenido de forma web, sin inventar experiencia o resultados que no aparezcan en los documentos.
